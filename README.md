# Xóm Mình

Ứng dụng cho vòng tròn bạn bè và các gia đình: điểm danh, rủ kèo, xung phong đăng cai, chat, Miếu Thần Tài (thắp hương, xin xăm, thầy bói).

- `demo/` — bản demo một trang (dữ liệu lưu trên máy người dùng), đang chạy tại https://xom-minh.netlify.app
- Bản thật (PWA + Supabase) sẽ được xây trong thư mục gốc theo kế hoạch các giai đoạn.
